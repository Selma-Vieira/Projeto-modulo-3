📊 Relatório Financeiro Global – Power BI
📌 Visão Geral
Este projeto apresenta um relatório interativo em Power BI que analisa as exposições financeiras dos países e seu crescimento anual. O objetivo é fornecer uma visão clara e dinâmica sobre tendências econômicas globais, permitindo comparações entre diferentes regiões e períodos.

🎯 Objetivos
Monitorar a evolução financeira anual dos países.

Identificar padrões de crescimento e exposição econômica.

Facilitar a análise comparativa entre diferentes regiões.

Apoiar a tomada de decisão estratégica com dados visuais e interativos.

🗂️ Estrutura do Relatório
O relatório está dividido em seções principais:

Visão Global – Panorama geral das exposições financeiras por país.

Crescimento Anual – Evolução do crescimento financeiro ao longo dos anos.

Comparações Regionais – Análise comparativa entre continentes e blocos econômicos.

Detalhes por País – Drill-down para explorar dados específicos de cada nação.

📈 Principais Indicadores
PIB anual

Taxa de crescimento econômico

Exposição financeira internacional

Participação relativa no mercado global

🛠️ Tecnologias Utilizadas
Power BI Desktop – Modelagem e visualização dos dados.

Excel/CSV – Fonte de dados brutos.

DAX – Criação de medidas e cálculos personalizados.

🚀 Como Utilizar
Abra o arquivo .pbix no Power BI Desktop.

Navegue pelas páginas do relatório para explorar os indicadores.

Utilize os filtros e segmentações para análises específicas.

Exporte visualizações conforme necessário para apresentações ou relatórios externos.
